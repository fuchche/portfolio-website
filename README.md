# Yubaraj Shrestha - Professional Portfolio Website

A modern, responsive, and high-performance personal portfolio website for **Yubaraj Shrestha** — Computer Science Teacher, Full Stack Web Developer, Graphic Designer, and AI Enthusiast.

## 🌟 Key Features

- **Modern Glassmorphism Design System**: Dark/Light mode toggle with smooth persistence using `localStorage`.
- **Dynamic Typing Animation**: Powered by Typed.js for eye-catching hero headers.
- **Interactive Background Particles**: Custom lightweight HTML5 Canvas particle network.
- **Animated Skill Bars & Counter Metrics**: Automatically trigger when scrolled into viewport using `IntersectionObserver`.
- **Interactive Portfolio Gallery**: Filterable showcase for Websites, Graphic Designs, Teaching Projects, and Certificates.
- **Full Timelines**: Interactive vertical experience and education history with animated entry points (AOS).
- **Certificate & Blog Reading Modals**: Bootstrap 5 interactive popups with detailed metadata.
- **Functional Contact Form**: Client-side validation with feedback notifications and Google Maps integration.
- **SEO & Accessibility Optimized**: Built with semantic HTML5, Open Graph tags, Twitter Card meta tags, and JSON-LD Structured Data (`Person` schema).

## 🛠️ Technology Stack

- **HTML5 & CSS3**: Custom CSS Variables, Flexbox, CSS Grid, Glassmorphism.
- **Bootstrap 5.3.3**: Grid system, modals, carousels, forms.
- **Vanilla JavaScript (ES6+)**: ScrollSpy, theme toggle, particle canvas, filters, smooth scroll.
- **Font Awesome 6**: Vector icons for social links, skills, and contact cards.
- **AOS (Animate On Scroll)**: On-scroll scroll reveal library.
- **Typed.js**: Animated headline typist.
- **Google Fonts**: Poppins (Headings) & Inter (Body Text).

## 📁 File Directory Structure

```
portfolio/
├── index.html          # Primary semantic HTML5 structure with SEO metadata
├── css/

│   └── responsive.css  # Mobile-first and desktop media queries

├── assets/
│   ├── robots.txt      # Search engine crawl configuration
```

## 🚀 How to Run

1. Simply open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari).
2. No Node.js build process or backend server required! All assets and libraries load via high-availability CDNs.
